# Flutter Portfolio App

A personal portfolio application built using Flutter during a workshop.

## Features

* Personal profile section
* About Me section
* Skills display using Flutter Chips
* Contact buttons (Website, Email, Phone)
* Favorite song card with Spotify integration
* Custom UI with gradient background

## Technologies Used

* Flutter
* Dart
* url_launcher package

## Learning Outcomes

Through this project I learned:

* Flutter widgets
* Stateful and Stateless widgets
* Layout design using Rows, Columns, and Containers
* External URL launching
* Basic mobile UI development
